# Music app design direction: Sound Workshop

Design a playful, welcoming music-learning app around a colourful sound workshop. The identity should welcome children and older beginners, with curiosity, humour, agency and enough quiet space to use it comfortably.

## The decisions

| Element | Starting decision |
| --- | --- |
| Display type | Grandstander 650 for short headings, around 36/40 CSS px |
| Reading and controls | Atkinson Hyperlegible Next 400/650; body 18/27 px; labelled actions 18 px |
| Canvas / ink | #FFF8E8 / #2B2341 |
| Main action | #3658D4 with white text |
| Accents | Coral #FF7954, yellow #FFD65C, mint #A7DFC3, lilac #C4B4E8, all with plum labels |
| Visual grammar | Related circles, arches, bars and loops; crisp printed geometry and limited irregularity in artwork |
| First impression | A clear playable action, then optional guidance and further exploration |
| Input | Generous web controls starting at 48-56 CSS px; larger playable pads; keyboard support and alternatives to essential dragging |
| Feedback | A visible and audible consequence of the user's action; optional decorative effects and reduced motion |
| Learner agency | Explore, undo, replay and save; clear return paths; specific encouraging feedback |

Keep the reading surface clear. Start without gradients, glossy 3D, random doodles, textures behind text or a dashboard of metrics above the instrument. These are choices for this direction, not claims that those styles are universally wrong.

Make the home, instrument, prompt, settings and error state coherent before adding more illustration. Use icons with clear labels. Test enlargement, longer translated labels, focus, selected/pressed states and disabled controls.

Avoid universal claims about colour psychology or a dyslexia-friendly font. The proposed choices need actual learner testing. Children, older beginners, disabled musicians, parents and teachers may need different information or controls while sharing the same identity.

These checks do not certify the complete palette, interface or app. The alternate boards require their own contrast and state checks. CSS px, iOS pt and Android dp are different units.
