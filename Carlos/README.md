# MasterTech Challenge 2026 - Canberra hub team

- Team: Simone, Justin, Carlos. Track: Cisco Live 2026 MasterTech Challenge, run by NIIN.
- The question: "How might we use AI and emerging technology to transform the way students learn and succeed?"
- This repo is private. Keep it private: it holds advisors' words, programme material and our own ideas.

## Ownership and sources
- Everything built in the programme is owned by La Trobe University and assigned to the industry sponsor (Participant Agreement).
- Only fresh, original work goes in. No material from any of our employers, internships or other projects.
- Research files cite public sources with URLs; quotes from advisors are approximate and marked as such.

## How to use this repo
- Start with notes/findings-gist-2026-11-08.md, then notes/friday-selection-pack-2026-11-06.md and the research files it points to.
- One file per topic, markdown. Add a line to the file index below when you add one.
- Writing style: dash bullets, "o" sub-bullets, about 15 words a bullet, numbers in tables. Short beats long.
- Pull before you edit, commit small, write what changed in the message. Everyone commits to main.
- Audio and video never go in; transcripts only. Personal data about students in tests: none, ever.
- Decisions go in decisions-log.md with a reason. Questions for advisors go in questions-for-sponsor.md.
